# ANISH / KARMA X — Website V3

A motion-first artist experience + press kit for ANISH and KARMA X.

## What is new in V3
- Cinematic animated intro using the supplied artist imagery
- Full-screen identity transition wipe between ANISH and KARMA X
- Motion-driven hero photography and scan effects
- Dedicated ANISH and KARMA X showreel sections
- Parallax image movement on desktop
- Animated cursor interactions
- Stronger transition section between both identities
- Motion-enhanced EPK tabs and downloads
- Responsive layout + reduced-motion accessibility support

## Video-ready setup
There were no MP4/MOV files in the supplied asset package, so V3 uses cinematic still-image motion rather than pretending stills are real video.

When real showreel files are ready, put them inside:
`assets/video/`

Suggested names:
- `anish-showreel.mp4`
- `karma-x-showreel.mp4`

The two showreel sections are already designed so the moving still can be replaced by a looping `<video>` element without changing the page layout.

## Run locally
Open `index.html` directly, or run a simple local web server in this folder.

## Free deployment
Upload this folder to GitHub and connect the repository to Cloudflare Pages. No paid hosting is required.
